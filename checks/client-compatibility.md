# Client Evidence Boundary

Initial target clients are Codex and Claude Code in local consumer checkouts. Actual versions,
CLI/IDE surfaces and root/nested access must be recorded per trial. The complete composed source
at its final revision still needs actual agent-use trials in both pilot consumers; prototype
observations are historical and do not certify this extracted tree. No new runtime pass is claimed
by this table. Hosted review is an optional workflow mode, not an additional supported agent client.

| Consumer role | Codex | Claude Code |
| --- | --- | --- |
| Go consumer | Final composition trial not run | Final composition trial not run |
| Java consumer | Final composition trial not run | Final composition trial not run |

Use [client scenarios](client-compatibility-scenarios.md) and
[security scenarios](agent-security-scenarios.md). Preserve original failures and identity gaps.
Record canonical file reads and observed actions, profile/revision/specification, cwd, tools and
host permissions. A document walkthrough is not enforcement evidence. Failed/absent required
capabilities block the affected claim; no alternate host inherits a pass from another surface.

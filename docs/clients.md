# Client Support and Verification

## Supported scope

Initial adoption targets Codex and Claude Code in local consumer checkouts. Adapter templates
support root AGENTS.md plus `.agents/skills/<workflow>/SKILL.md` for Codex, and root CLAUDE.md plus
`.claude/skills/<workflow>/SKILL.md` for Claude. Each client has six adapters pointing to the same
canonical skills in the dependency; links do not automatically prove their targets were read.

Prerequisite disposable trials observed Codex CLI 0.156.1 and Claude Code CLI 2.1.309. These are
historical tested identities, not required permanent versions or final-source certifications.
A Claude CLI capacity interruption remained a failed observation; a later IntelliJ continuation
supplied missing actions but did not establish unavailable IDE/SDK versions. Those limitations
must remain in the consumer evidence. Do not claim equivalent CLI, IDE, hosted or cloud behavior.
Continue and GitHub Copilot are outside this pilot's support scope; optional hosted review is
workflow policy rather than an additional supported client.

## Root resolution and trial matrix

Launch with access to the consumer root and its pinned dependency even when cwd is a nested
module. Resolve consumer root before framework root, discover applicable ancestor/nested guides,
then read the profile, exported consumer contract, selected rules and full requested skill.
A host access denial is a blocked trial, never permission to bypass it through another tool.
Keep explicit root/profile/framework identity and observed canonical reads in the record.

| Consumer | Codex final-checkout trial | Claude final-checkout trial |
| --- | --- | --- |
| Insurance Hub | Required at adoption; not certified by shared-source tests | Required at adoption; retain actual host/version limits |
| campsite-booking | Required at adoption on the same framework pin | Required at adoption on the same framework pin |

In each cell, test root assessment, nested specification, plan-only stopping point, a permitted
implementation/post-step cycle and read-only seeded review. Include missing canonical skill,
missing binding, unavailable artifact exclusion, nested conflict and numbered-issue synchronization
failure. Confirm Go-only selection, Java API-plus-test and the applicable Google/local choice.
No fixture may authorize real publication, alter active exclusions or mutate unrelated source.

Record client/model/version/host/cwd/permission mode, framework commit/tree, consumer/profile/
adapter/specification identities, exact prompts/commands, actual reads/actions and resulting files.
Use synthetic tickets with approved local artifact handling. Correct-looking text/static routing
alone is insufficient. Re-run affected cells after a pin, adapter, instruction or material host
change. No whole-host/network isolation claim follows from CLI option names.
